### Automatic Sensitivity Label Inheritance

The **Confidential – PHI Data** sensitivity label was automatically applied to the outbound email based on the classification of the attached document. Microsoft Purview also generated a policy tip indicating that the message conflicted with the organization's DLP policy.

This demonstrates how sensitivity labels can propagate from protected attachments to email messages while DLP independently evaluates the attempted external sharing activity.
