# Microsoft Purview Governance Lab

## Executive Summary

This repository documents the design and implementation of a Microsoft Purview information governance solution for Knapp Healthcare, a fictional regional healthcare organization.

The project follows a realistic enterprise implementation methodology, beginning with business requirements and data discovery before progressing through information classification, information protection, and governance.

The repository combines hands-on Microsoft Purview configuration completed in a Microsoft 365 lab environment with implementation documentation for enterprise capabilities that require additional Microsoft Purview licensing.

The objective of this project is to demonstrate how Microsoft Purview can be used to help organizations discover, classify, protect, and govern sensitive information while supporting regulatory compliance and reducing organizational risk.

---

# Business Scenario

Knapp Healthcare is a regional healthcare organization with approximately **2,500 employees** operating across:

- Three hospitals
- Eight outpatient clinics
- Administrative offices
- Finance and Billing
- Human Resources
- Clinical Research
- Information Technology

Following several information governance incidents involving employee, financial, and patient data, executive leadership approved a Microsoft Purview implementation to improve information protection, strengthen governance, and reduce the risk of data loss.

---

# Business Challenges

During the initial assessment, the following business risks were identified:

- Payroll information was accidentally shared with an external recipient.
- Patient records were stored in an unauthorized cloud location.
- Financial information lacked consistent classification and protection.
- Sensitive healthcare data had accumulated across Microsoft 365 with limited visibility.
- Security teams required improved discovery and classification of regulated data.

---

# Project Objectives

As the Microsoft Purview Analyst, my responsibilities included:

- Gathering business requirements
- Performing a data inventory
- Designing an enterprise data classification strategy
- Implementing Microsoft Purview sensitivity labels
- Publishing sensitivity labels through label policies
- Configuring auto-labeling policies
- Exploring Microsoft Purview Data Governance capabilities
- Designing Data Loss Prevention (DLP) strategies
- Documenting governance and information protection processes

# Lessons Learned

This project reinforced several important aspects of implementing Microsoft Purview in an enterprise environment:

- Successful information governance begins with understanding business processes and sensitive data.
- Effective information protection depends on well-designed classification and labeling strategies.
- Microsoft Purview licensing directly impacts the availability of advanced governance and protection capabilities.
- Enterprise implementations require balancing technical configuration with business requirements and compliance objectives.
