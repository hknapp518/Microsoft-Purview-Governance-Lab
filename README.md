# Microsoft Purview Governance Lab

## Project Overview

This repository documents the design and partial implementation of a Microsoft Purview information governance solution for **Knapp Healthcare**, a fictional regional healthcare organization.

The project follows a real-world implementation methodology and demonstrates how Microsoft Purview can be used to classify, protect, and govern sensitive organizational information.

The implementation combines hands-on Microsoft Purview configuration completed in a Microsoft 365 lab environment with implementation documentation for features that require additional Microsoft Purview licensing.

---

# Business Scenario

Knapp Healthcare is a regional healthcare organization with approximately 2,500 employees operating across hospitals, outpatient clinics, and administrative offices.

Following several data governance incidents involving sensitive employee, financial, and patient information, executive leadership approved a Microsoft Purview implementation to strengthen information governance, reduce data loss, and improve regulatory compliance.

---

# Business Challenges

The organization identified several key risks:

- Employee payroll information was accidentally shared with an external recipient.
- Patient records were stored in an unauthorized cloud location.
- Financial information lacked consistent classification and protection.
- Sensitive healthcare data required improved discovery and governance.
- Security teams required better visibility into sensitive information across Microsoft 365.

---

# Project Objectives

As the Microsoft Purview Analyst, my responsibilities include:

- Gathering business requirements
- Performing a data inventory
- Designing an information classification strategy
- Implementing Microsoft Purview sensitivity labels
- Publishing sensitivity labels through label policies
- Configuring auto-labeling policies
- Designing Data Loss Prevention (DLP) strategies
- Documenting governance and information protection processes

# Implementation Summary

The following Microsoft Purview components were configured in a Microsoft 365 lab environment:

- Sensitivity Labels
- Sensitivity Label Publishing Policy
- Auto-labeling Policy (Simulation)
- Financial Sensitive Information Detection Rule
- Microsoft Purview Unified Catalog

Some advanced Microsoft Purview capabilities require Microsoft 365 E5 or Microsoft Purview licensing. Where licensing limitations prevented full deployment, implementation designs and supporting documentation were developed based on Microsoft best practices.
